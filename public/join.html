Report a blocked drain

Anyone in Accra can report a drain. It is free. You do not need a password or a photo.

  1. Enter your phone number below.
  2. Enter the 6-number code we send you by text message.
  3. Tell us how the drain is and where it is. We will message you when a crew clears it.
